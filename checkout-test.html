Verificar o acesso ao checkout

Esta página ajuda a testar se o botão de compra encaminha para o checkout associado à formação. Não é necessário nem recomendado concluir uma compra para fazer o teste inicial.

Preço de referência na página: 35.000 AOA
Abrir checkout numa nova aba →

Link configurado. Ao clicar, o checkout abre num novo separador.

Lista de verificação

  1. Confirma que a página de checkout abre sem erro.
  2. Confirma que o nome do produto corresponde a “Compliance Nível Básico”.
  3. Confirma o preço final e se existem taxas adicionais antes de pagar.
  4. Verifica os métodos de pagamento disponíveis para ti.
  5. Confirma as condições de acesso, garantia e reembolso apresentadas pelo vendedor.
  6. Testa o botão de compra da página principal no telemóvel e no computador.

Importante: a página de teste não consegue confirmar automaticamente se o checkout externo está operacional ou se a atribuição de afiliado foi registada. Isso só pode ser confirmado abrindo o checkout e, para a atribuição, consultando os relatórios ou o suporte da plataforma. Não introduzas dados de pagamento nem concluas uma compra apenas para testar.
